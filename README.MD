# SUAONG – Sistema de Oportunidades de Emprego

Projeto acadêmico desenvolvido para facilitar a divulgação de vagas de emprego e a candidatura de pessoas interessadas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- Node.js
- Express
- MySQL

## Banco de dados

O banco de dados utilizado no projeto é `suaong_db`.

Ele possui três tabelas principais:

- **candidato:** armazena os dados dos candidatos.
- **vaga:** armazena as oportunidades de emprego.
- **candidatura:** registra as inscrições dos candidatos nas vagas.

O script de criação do banco está disponível em `database/schema.sql`.

## Como executar o projeto

1. Instale as dependências com `npm install`.
2. Inicie o projeto com `npm run dev`.
3. Acesse o endereço informado pelo Vite no terminal.

## Objetivo

Desenvolver um sistema web para aproximar candidatos e oportunidades de emprego.
